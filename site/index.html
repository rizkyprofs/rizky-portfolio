How this site is deployed

  1. Push to GitHubEvery change to the site goes through a pull request on the main branch.
  2. GitHub Actions builds the imageA multi-stage Docker build packs the site into a small Nginx image.
  3. Trivy scans itThe pipeline fails on serious vulnerabilities before anything is published.
  4. Image goes to Amazon ECRTagged with the commit hash, so every release can be traced and rolled back.
  5. Argo CD syncs the clusterIt watches the Helm chart in Git and applies changes to Kubernetes on its own.
  6. K3s on AWS EC2 serves trafficTraefik Ingress and cert-manager (Let’s Encrypt) handle routing and HTTPS.
  7. Prometheus, Grafana and Loki watch itMetrics, dashboards, and logs show uptime and resource use.
